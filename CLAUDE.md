# CLAUDE.md

Course materials for a beginner **Data Science course**: mathematics for DS (statistics and linear algebra on real
data), followed by classic ML. The course is in active development. Teaching materials are in **Russian**; code
comments and documentation are in **English**.

## Read first

- [docs/COURSE_MAP.md](docs/COURSE_MAP.md): what exists, the teaching order, **what students already know** (§6),
  and open questions. It is the source of truth for course content.
- [docs/AGENT_PROTOCOL.md](docs/AGENT_PROTOCOL.md): how to work here. It covers agreeing before building, rebuild
  rules, the lesson spec and the validation checklist.
- `syllabus.docx`: the 16-week plan (Russian). A compass, not a contract. AGENT_PROTOCOL §1 shows how to read it.
- External: the datasets are on HF [`aiacademy-kg`](https://huggingface.co/aiacademy-kg); the dataset scrapers, with
  field documentation, and the seminar repos are in GitHub [`ai-academy-bish`](https://github.com/orgs/ai-academy-bish/repositories)
  (COURSE_MAP §8).

## Commands

```bash
python3 -m venv venv && venv/bin/pip install -r requirements.txt       # local environment (Python 3.12)
venv/bin/python math_for_ds/build_lessonN.py                           # N = 2..8; writes math_for_ds/NN_*.ipynb
cd practice/phones && ../../venv/bin/python build_phones.py            # practicum scripts write to the current directory
open DT/theory/index.html                                              # DT theory handbook (offline; MathJax from a CDN)
```

There are no tests. Validation is the checklist in AGENT_PROTOCOL §7.

## Rules (details in AGENT_PROTOCOL)

1. **Agree on structure before building** any new lesson or practicum: propose a plan, ask the questions that matter,
   and wait for an "ok".
2. **Use only taught concepts** in tasks (COURSE_MAP §6). For example, there is no correlation, regression or
   hypothesis testing yet.
3. **Never run `build_lesson1.py`.** L1 is edited by hand. Rebuilding L4 drops its 17 in-class cells, so ask first.
   `seminar_1`, both bus practicum notebooks in `practice/`, `DT/` and `unsupervised/` have no build scripts;
   edit those notebooks directly.
4. **Lesson format:** Colab `.ipynb`, committed un-executed; dark HTML theory in collapsed `#@title` cells; every
   output self-contained; live JS/SVG widgets; MathJax `$…$` / `$$…$$` only; a «Где:» glossary under every formula.
5. **Language:** prose and UI strings in Russian (academic, textbook tone, no conversational metaphors); code comments
   and docstrings in English.
6. **No ready answers** in student notebooks. Hints are given in words; answers go into KEY versions only.
7. **Data:** never download the `images` configs or raw feeds. Local data go into gitignored `data/`. Pin revisions of
   datasets that keep changing.
8. **After adding or changing material, update `docs/COURSE_MAP.md`** (sequence, notes, concept inventory, changelog).
9. **Do not commit or push unless asked.**
