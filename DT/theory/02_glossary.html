Глава 2

Глоссарий терминов

Терминология в машинном обучении почти всегда англоязычная: в статьях, в документации scikit-learn, в названиях гиперпараметров. Поэтому здесь мы собираем английские термины с переводом и коротким пояснением — а дальше по тексту используем именно их, не переключаясь каждый раз. Таблицы сгруппированы по темам; внутри — по логике изложения, а не по алфавиту.

Как читать таблицы
Первый столбец — английский термин (как вы встретите его в коде и статьях), второй — русский эквивалент, третий — пояснение в одну-две фразы. Подробный разбор каждого понятия — в соответствующей главе.

Базовые понятия обучения

Термин (EN)ПереводПояснение
featureпризнак Измеримая характеристика объекта (площадь квартиры, длина лепестка). Колонка в таблице данных.
target / labelцелевая переменная / метка То, что модель предсказывает: число (регрессия) или класс (классификация).
sample / objectобъект / наблюдение Одна строка данных — один пример с признаками и (на обучении) ответом.
supervised learningобучение с учителем Учимся по парам «объект → правильный ответ».
regressionрегрессия Задача предсказания числа ($y \in \mathbb{R}$).
classificationклассификация Задача предсказания класса из конечного набора.
loss functionфункция потерь Штраф за расхождение прогноза с истиной; её минимизируют при обучении.
empirical riskэмпирический риск Средняя потеря на обучающей выборке.
train / test splitобучающая / тестовая выборки Деление данных: на одной учимся, на другой честно проверяем.
cross-validation (CV)кросс-валидация Многократная проверка на разных разбиениях для устойчивой оценки качества.
overfittingпереобучение Модель «зазубрила» обучающие данные вместе с шумом и плохо обобщает.
underfittingнедообучение Модель слишком простая, не улавливает закономерность.
generalizationобобщающая способность Качество модели на новых, не виденных данных.
hyperparameterгиперпараметр Настройка, которую задают до обучения (глубина дерева, число деревьев).

Решающие деревья

Термин (EN)ПереводПояснение
decision treeрешающее дерево Модель из вложенных условий «если признак $<$ порог …», нарезающая пространство на области.
nodeузел Точка дерева, где происходит проверка условия.
leafлист Конечный узел; в нём лежит готовый ответ (класс или число).
splitразбиение Деление выборки узла на левую и правую части по признаку и порогу.
thresholdпорог Значение $s$, по которому делят: $x_j < s$ — налево, иначе — направо.
impurityнеоднородность / нечистота Мера «перемешанности» узла $H(R)$. Чистый узел (один класс) — нулевая.
entropyэнтропия Критерий неоднородности $-\sum_k p_k\log p_k$.
Gini impurityкритерий Джини Критерий неоднородности $\sum_k p_k(1-p_k)$.
information gainинформационный выигрыш Насколько разбиение снижает неоднородность; его максимизируют при выборе сплита.
feature importanceважность признаков Оценка вклада признака в качество модели.
stumpпень Дерево глубины 1 (один сплит). Главный «слабый» базовый алгоритм бустинга.

Разложение ошибки

Термин (EN)ПереводПояснение
biasсмещение Систематическая ошибка модели — насколько «в среднем» она мимо. Высокое у слишком простых моделей.
varianceразброс Чувствительность модели к конкретной обучающей выборке. Высокий у слишком гибких моделей.
irreducible noiseнеустранимый шум Случайность в данных $\sigma^2$, которую не предскажет ни одна модель.
bias–variance tradeoffкомпромисс смещения и разброса Уменьшая одно, обычно увеличиваешь другое; ищем баланс по сложности модели.
model complexityсложность (гибкость) модели Способность подстраиваться под данные (глубина дерева, степень полинома).

Ансамбли: усреднение

Термин (EN)ПереводПояснение
ensembleансамбль Композиция многих моделей, работающая лучше любой одиночной.
bootstrapбутстрэп Выборка того же размера, взятая с возвращением из исходной.
baggingбэггинг Bootstrap AGGregating: обучить модели на бутстрэп-выборках и усреднить.
random forestслучайный лес Бэггинг над деревьями + случайный отбор признаков в каждом узле.
out-of-bag (OOB)вне-сумочная оценка Бесплатная валидация: каждый объект проверяют на деревьях, в чьей бутстрэп-выборке его не было.
decorrelationдекорреляция Снижение похожести моделей ансамбля; делает усреднение эффективнее.
max_featuresчисло признаков на узел Сколько случайных признаков рассматривать в сплите; рычаг декорреляции в лесе.

Ансамбли: бустинг

Термин (EN)ПереводПояснение
boostingбустинг Последовательное построение моделей, каждая исправляет ошибки предыдущих.
gradient boostingградиентный бустинг Бустинг, где каждая новая модель приближает антиградиент функции потерь.
weak learnerслабая модель Простой базовый алгоритм (обычно неглубокое дерево), чуть лучше случайного.
residualостаток Разница между истиной и текущим прогнозом, $y - F(x)$.
pseudo-residualпсевдо-остаток Антиградиент потерь $-\partial \ell/\partial F$; для MSE совпадает с обычным остатком.
learning rateтемп обучения Множитель $\eta$ при каждой новой модели; длина шага спуска.
shrinkageсжатие То же, что маленький $\eta$: «придерживаем» вклад каждого дерева ради устойчивости.
n_estimatorsчисло базовых моделей Сколько деревьев в ансамбле (итераций бустинга / деревьев леса).
subsampleдоля подвыборки Доля объектов на каждой итерации; стохастический бустинг, прямая аналогия SGD.
early stoppingранняя остановка Прекратить добавлять деревья, когда качество на валидации перестало расти.
SGDстохастический градиентный спуск Градиентный спуск по случайным мини-порциям данных; идейный родственник бустинга.
Главное
Не пугайтесь английских названий гиперпараметров — почти все они дословно повторяют термины из этой таблицы: n_estimators, max_features, learning_rate, subsample. Зная смысл термина, вы уже знаете, что крутит соответствующая ручка.
