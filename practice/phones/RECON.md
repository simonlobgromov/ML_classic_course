# Разведка датасета `aiacademy-kg/lalafo-kg-phones`

> Цель разведки: понять, что внутри, где «говно», и какие **маленькие** самостоятельные
> задачи можно дать новичкам, чтобы они отработали изученное (векторы, скалярное
> произведение/косинус, описательная статистика, боксплоты) — с визуализацией и защитой.
> Фотографии (конфиг `images`, ~5 ГБ) **не качаем** — они пока не нужны.

## 1. Что за датасет

Это выгрузка объявлений о продаже телефонов с доски **Lalafo (Кыргызстан)**. 4 таблицы (конфига):

| Конфиг | Строк | Размер | Что это |
|---|---:|---:|---|
| **`listings`** | **8 160** | 7.2 МБ | ⭐ Главная таблица — объявления. С ней и работаем. |
| `users` | 6 605 | 0.5 МБ | Продавцы: `response_rate`, `ads_count`, `is_banned`, `pro`. |
| `cities` | 175 | 0.01 МБ | Справочник городов и регионов. |
| `images` | 37 627 | **4.9 ГБ** | Сами фото. **Игнорируем.** |

### Как грузить БЕЗ фото (для Colab одной строкой)

```python
import pandas as pd
URL = "https://huggingface.co/datasets/aiacademy-kg/lalafo-kg-phones/resolve/refs%2Fconvert%2Fparquet/listings/train/0000.parquet"
df = pd.read_parquet(URL)          # 8160 строк, 71 колонка, ~7 МБ
```

Через `datasets` — тоже можно, но обязательно указывая конфиг `listings` (иначе потянет `images`):
```python
from datasets import load_dataset
df = load_dataset("aiacademy-kg/lalafo-kg-phones", "listings", split="train").to_pandas()
```

## 3. Качество данных — где «говно» (и почему это подарок для занятий)

### 3.1 Пропуски (доля NaN)
```
national_price 99% | battery_health 69% | old_price 68% | device_class 63%
imei_status 53% | ram 53% | sim 43% | condition 36% | storage 21%
region 19% | price 12% | color 11% | currency 6%
```
`price` пуст у **12%** объявлений, `currency` — у 6%. То есть «просто взять и усреднить цену» не выйдет — сначала чистка.

### 3.2 Цена — заповедник выбросов ⭐
- Валюта: `KGS` 7604, `USD` 65, `NaN` 491. **Смешаны валюты** → нельзя сравнивать в лоб.
- `min = 1`, `max = 1 978 421 349` (почти 2 **миллиарда** сом).
- **`mean ≈ 4.37 млн`, а `median = 18 000`** — среднее раздуто выбросами в ~240 раз. Живой пример «как выброс ломает среднее».
- Мусор снизу: 12 цен ≤ 1, 57 ≤ 100, 132 ≤ 500 сом.
- Мусор сверху: 37 цен > 1 млн.
- Правило `1.5·IQR` (только KGS): границы `[-41250, 88750]`, выше — **327 объявлений (4.6%)**.

**Кто эти «миллиардеры»?** — это НЕ телефоны, а спам перекупов:
```
1 978 421 349  «Все виды телефонов за наличку и в рассрочку»
1 236 548 868  «Redmi»
1 234 567 890  ← кто-то просто набрал 1234567890
1 213 467 807  «Скупка телефонов дорого!»
```
Фейковая цена = маркер спам-объявления. Красиво сшивает темы «выбросы» и «чистка мусора».

### 3.3 Числа, которые хранятся строками (нужен парсинг)
- `storage`: `"256 ГБ"`, `"128 ГБ"`, `"1 ТБ"`, а ещё `"< 2 ГБ"`, `"< 16 ГБ"` (с «меньше»!).
- `ram`: `"8 ГБ"`, `"12 ГБ"`, `"< 2 ГБ"`.
- `battery_health_pct`: строки `"100"`, `"84"`… **но есть один ввод `123 658 674`** — из-за него среднее «здоровье батареи» = **49 333 %** вместо медианных **86 %**. Один опечатавшийся человек — и статистика сломана. Идеальная иллюстрация к уроку про выбросы.

### 3.4 Дубли и перекупы (спам)
- **681** повторяющийся `title`, **548** строк с общим `description`.
- Топ-«продавцы»: у одного **160** объявлений, у другого 133, 123. Всего **23** юзера с ≥20 объявлений — это магазины/скупка, а не частники.
- Повторяющиеся заголовки — реклама рассрочки/скупки:
  `📱 СКУПКА ТЕЛЕФОНОВ — ДОРОГО…`, `🔥 IPHONE, SAMSUNG … рассрочка`, `🏠 БАРДЫК ҮЙ ТЕХНИКАЛАРЫ` (×34).

### 3.5 Смесь языков
`title`: латиница 93% (бренды iPhone/Samsung), кириллица 99.7%, кыргызские буквы `ө/ү/ң` — 0.9%.
То есть в основном русский с латинскими названиями моделей, кое-где кыргызский. Средняя длина заголовка 56 символов.

## 5. Меню задач: тема курса → что делать студенту

> Принцип: **одна тема — одна маленькая гипотеза — один график — один вывод.** Первый проект.

### Тема 1. Векторы (точка в пространстве признаков, норма, операции)
- Представить объявление как вектор `[price, storage_gb, ram_gb, views, favorite_count]`.
- Посчитать **норму**; понять, почему без нормировки всё определяет `price` (тысячи vs единицы).
- Мостик к z-стандартизации из статистики.

### Тема 2. Скалярное произведение / косинус / euclidean vs cosine / ближайший сосед
- **«Найди 5 похожих телефонов»** на заданное объявление через косинусную близость векторов признаков.
- Показать разницу **euclidean vs cosine**: евклид «липнет» к цене, косинус ловит «профиль» телефона.
- (Продвинуто) bag-of-words по `title` → косинус → сами собираются кластеры брендов.

### Тема 3. Описательная статистика, группы, гистограммы, KDE, центроиды, z-оценка
- `groupby('brand'/'model').price.median()` → barplot (готовые лестницы из §4.1–4.2).
- Гистограмма/KDE цен — обязательно в **log-масштабе** (сильный скос).
- **2D KDE + центроиды**: облако `(views, favorite_count)` или `(storage_gb, price)`, центры масс по брендам — где «сидит» Apple против Redmi.
- z-стандартизация признаков перед сравнением векторов (мостик к теме 1–2).

### Тема 4. Непараметрика: перцентили, боксплоты, IQR, RobustScaler
- Боксплот цен → выбросы; вытащить и показать спам-«миллиардеров».
- **«Как выброс ломает среднее»** на `battery_health_pct`: 49 333 % → убрать 1 мусор → 86 %.
- Чистка `1.5·IQR` vs чистка по перцентилям (1% с краёв) — сравнить, сколько удаляется.
- RobustScaler против обычной стандартизации на скошенных ценах.

### Сквозная тема. Чистка «говна» (нужна почти для любого сюжета выше)
Привести валюту к одной; распарсить `storage/ram/battery` из строк в числа (regex, учесть `"< 2 ГБ"`, `"1 ТБ"`); отсеять дубли/спам; разобраться со смесью языков.
