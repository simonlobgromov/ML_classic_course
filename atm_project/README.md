# MBank ATM — синтетический датасет (Бишкек, 2024–2025)

Учебный проект: правдоподобная имитация операционной даты сети из 120 банкоматов
банка MBank в Бишкеке за 2 года. Полная спецификация — в [design.md](design.md).

## Что уже готово

Справочники (dimension-таблицы) звёздной схемы — генерируются за ~2 сек:

| Таблица | Строк | Описание |
|---------|-------|----------|
| `dim_district` | 16 | зоны Бишкека (районы, рынки, жилмассивы) с координатами |
| `dim_calendar` | 731 | дни с праздниками КР, климатом, курсом USD/KGS, payday |
| `dim_atm` | 120 | банкоматы: тип локации, «железо», ёмкость, install_date |
| `dim_customer` | 550 000 | клиенты: демография, источник дохода, сегмент |
| `dim_card` | 700 000 | карты: схема, продукт, эмитент |

Ещё не сделано: порождающая модель и `fact_transactions` (посекундные снятия),
`fact_cash_ops`, `fact_atm_status` — следующий этап.

## Запуск

```bash
# из папки atm_project
../venv/bin/python -m generator.build_dims
```

Результат — в `data/` (Parquet + CSV-зеркало для мелких таблиц). Параметры
генерации — в [config.yaml](config.yaml).

## Структура

```
generator/
  geography.py   # dim_district: зоны Бишкека + привязка типов ATM
  calendar.py    # dim_calendar: праздники, климат, FX
  atms.py        # dim_atm: размещение и железо банкоматов
  customers.py   # dim_customer, dim_card
  build_dims.py  # сборка и запись всех справочников
```

`data/` и `meta/` в `.gitignore` (датасет не коммитим).
